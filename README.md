# agriculture-dashboard
🌱 Crop Cast – Agricultural Sensor Dashboard (Power BI Project)

# 📌 Project Overview

Crop Cast – Agricultural Sensor Dashboard is an interactive Power BI solution designed to analyze agricultural sensor data. It converts raw environmental readings—such as temperature, moisture, humidity, and rainfall—into meaningful visual insights that support smarter farming decisions and crop monitoring.

# 📝 Short Description

This Power BI dashboard transforms raw agricultural sensor data into meaningful insights. It helps users understand environmental patterns, detect anomalies, and monitor crop conditions in real time. With easy-to-read visuals and customizable filters, the dashboard allows farmers, researchers, and stakeholders to make informed decisions to improve agricultural productivity..

# 🛠️ Tech Stack

Power BI Desktop – Data modeling & dashboard creation

Power Query – ETL and data cleaning

DAX (Data Analysis Expressions) – Measures & calculated fields

CSV/Excel Integration – Data import and handling

Kaggle Dataset – Source of agricultural sensor data

# 📂 Data Source

Platform: Kaggle

Type of Data: Agricultural / Crop Sensor Data

Format: CSV files

# ⭐ Features & Highlights
# 1. Business Problem

Agriculture relies heavily on environmental conditions, but farmers often lack tools to interpret complex sensor-generated data. Without clear visualization, they struggle to identify trends, detect anomalies, optimize irrigation, or understand the overall field condition—leading to inefficient practices, resource wastage, and reduced crop yield.

# 2. Goal of the Dashboard

Convert raw agricultural sensor data into clear, interactive visual insights

Enable farmers and analysts to monitor temperature, humidity, moisture, and rainfall

Identify environmental patterns that affect crop growth

Support data-driven decisions in irrigation, fertilization, and resource planning

Present sensor data in a structured, accessible, and visually engaging format

# 3. Walkthrough of Key Visuals

KPI Cards: Quick view of average temperature, humidity, rainfall, and moisture

Line Charts: Trend analysis for environmental metrics over time

Sensor Comparison Visuals: Compare readings across different sensors

Heat Maps: Identify high/low moisture or temperature regions

Interactive Filters: Filter by sensor type, region, or date

Anomaly Indicators: Spot abnormal sensor readings instantly

Field-Level Breakdown: Analyze environmental conditions by specific zones or sensors

# 4. Business Impact & Insights

Optimized Irrigation: Moisture data helps reduce water waste and over-irrigation

Early Issue Detection: Identifies extreme weather patterns or soil problems

Better Crop Health: Supports timely actions to protect and improve crop conditions

Improved Resource Planning: Helps allocate water and fertilizers efficiently

Data-Driven Farming: Encourages smart agricultural decisions backed by analytics

Scalability: Dashboard can be extended with forecasting or yield prediction model
